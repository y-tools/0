# アナグラムガチャのデータアップロード

「全設定保存」で出力した `anagram-gacha-backup-*.json` を、メイン画面の「データアップロード」から読み込めます。形式は `ypp-anagram-gacha-backup`、バージョン1です。

取り込み前に、ダイス・名前・履歴・大当たり・連ガチャ・被り・天井設定の概要を表示します。「このデータを取り込む」を押すと、対象のアナグラム用保存キー8個を置き換え、画面へ反映します。「キャンセル」や閉じる操作では変更しません。必要なら同じ確認画面で、現在のデータを先にダウンロードできます。ファイルはブラウザ内で読み取り、サーバーへ送信しません。

UTF-8のJSON、2MB以下に対応します。ダイスは200個、履歴は10,000件、名前一覧は5,000人、大当たりは300件までです。ダイスは空欄または1書記素（絵文字・結合文字も含む）です。不明な形式・バージョン、壊れたJSON、範囲外の回数、不正な履歴日時、矛盾する天井設定などは取り込み前に拒否します。古いバージョン1バックアップで省略された追加設定には既定値を使います。

抽選中はアップロードを無効化します。保存に失敗した場合は変更前のアナグラム保存キーを復旧し、他ツールの保存キーには触れません。ブラウザ自体の保存機能が拒否されて復旧もできない場合は、その旨を表示し、画面内に残る現在のデータをダウンロードするよう案内します。

検証：`node tools/tests/anagram-backup.test.cjs`。実際の画面では、保存ボタンから出力したファイルの復元、再読み込み、キャンセル、不正ファイル、保存エラー時の復旧、連ガチャ、スマホ幅、他ツールの起動を確認しています。
