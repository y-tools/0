# Y++ — Tools Portal

スマートフォン中心のY++公式ツールポータル。

## 公開画面

- 上部ヘッダー Y++、右上ハンバーガーメニュー
- 8つのツールカード（OBS・役職ガチャは準備中、ほかは利用可能）
- Y-OBSの配信表示（配信なしのときは省スペース）
- 画像を使わないテキストプロフィール

## プロフィール編集

プロフィールの「PROFILE」見出し・名前・本文エリアを10回連続タップすると編集画面が開きます。
ユーザー操作だけで認可されるわけではなく、Y-OBSの管理用PINの認証と、サーバー側トークン検証を行います。

編集画面は常時 2×2 の4分割構成（スマホでも4枠）。

1. プレビュー：変更内容を即時反映
2. 基本情報：名前・ひとこと・紹介文
3. 週間イベントスケジュール：タイトルと内容のセット、複数追加・削除・移動
4. 基本ブロック：タイトルと内容のセット、複数追加・削除・移動

公開プロフィールは HTML として直接注入せず、テキストとしてレンダリングします。

## プロフィール保存API

静的なGitHub Pagesだけでは公開データの保存ができないため、Y-OBSサーバーの
`server/yobs-api.py` に次を追加済みです。

- `GET /api/profile`: 誰でも閲覧可能な公開プロフィール
- `POST /api/admin/profile`: Bearerトークン（既存のY-OBS管理ログイン）必須の保存API

保存先はサーバーの `YOBS_DATA/yplus_profile.json`。
編集データの文字数・種類・ブロック数を検証し、リビジョン番号による更新競合を検出します。
追加の公開トークンやGitHub APIキーはフロントには不要です。

**デプロイ注意**：Y-OBSのGitHubコード更新は稼働中のVPSへのデプロイではありません。
`GET /api/profile` が404の場合はY-OBS APIをVPSへ配置・再起動する必要があります。
それまではブラウザ内でのみ下書き保存でき、他端末や一般訪問者には反映されません。
プロフィールの編集画面はその状態を区別して表示します。

`YOBS_PROFILE_ORIGINS` にはプロフィール編集を許可する公開サイトのOriginをカンマ区切りで設定できます。
初期値は `https://y-tools.github.io`。独自ドメインに変更した場合は設定を更新してください。
APIは既存のY-OBSサーバープロセスで動かし、サーバーのアクセス権限に応じて保存先を適切に保護してください。

## セキュリティ

- 10回タップは認証ではなく編集画面への入口です。
- PINはフロントのソースにも公開設定ファイルにも保存しません。
- PINログインは既存Y-OBSの試行制限・禁止ルールを使用します。
- GitHubのアクセストークンをブラウザへ渡さず、Web編集とGitHubは切り離しています。
- プロフィールの内容はすべて文字列として描画します。
- 公開APIに資格情報不要の書き込み口を設けません。

## ローカル開発

`python3 -m http.server 8080` をルートで起動してください。
公開プロフィールは初期状態では `site.config.json` を使用します。
サーバー未配備の場合でもUI表示・編集下書き・JSON書き出しができます。


## 特設ビンゴ（VPS共有・パスワード管理）

公開ページ: https://y-tools.github.io/0/bingo/

- トップページの特設バナーからビンゴページに移動します。
- 現在のビンゴ画面は75球の抽選、履歴、端末内カード、BINGO/REACHの自動判定を表示します。
- 抽選状態はVPSの `/var/lib/yplus-bingo/state.json` が唯一の正本で、閲覧画面は `GET https://153-127-64-17.sslip.io/api/bingo/state` から読み込みます（約60秒間隔）。
- 管理画面はパスワードをVPS APIで認証します。パスワードをHTML/JSやGitHubのコミットには保存しません。
- 認証後のAPIは `POST /api/bingo/admin/action`。起動/一時停止/抽選/取り消し/終了/リセット/表示テキスト更新が可能です。
- APIは `server/bingo_admin.py` をVPSの `/usr/local/lib/yplus-bingo/bingo_admin.py` に配置し、`yplus-bingo.service` として127.0.0.1:8791で稼働します。
- HTTPSはCaddyの `153-127-64-17.sslip.io` サイトが `/api/bingo/*` を127.0.0.1:8791に転送します。既存のY-OBS `/api/*` とはルーティングを分離しています。
- 管理パスワードのscryptハッシュはVPSのroot専用 `/etc/yplus-bingo.env` に格納し、リポジトリには格納しません。
- 管理セッションはメモリ内のみで有効期間2時間。認証失敗を繰り返すと15分間の制限がかかります。
- VPSデータストアのファイルはバックアップ対象に含めてください。

**未実装の機能:** 参加者による名前での申請、承認/却下、参加者別カードのVPS保存、参加者一覧とステータス管理。現在のカードはまだ端末内発行です。抽選・管理者認証のVPS移行とは別タスクとして対応が必要です。

### 管理用パスワードの再設定

VPSで `python3 /usr/local/lib/yplus-bingo/bingo_admin.py hash-password` を実行し、新しいパスワードのscryptハッシュを取得してください。`/etc/yplus-bingo.env` の `YPLUS_BINGO_PIN_HASH` を差し替えて `sudo systemctl restart yplus-bingo` すると反映されます。ハッシュではなく平文のパスワードをファイルに保存しないでください。

### 動作確認

```sh
sudo systemctl status yplus-bingo
curl -fsS https://153-127-64-17.sslip.io/api/bingo/health
curl -fsS https://153-127-64-17.sslip.io/api/bingo/state
```

GitHub Issue #1は旧方式の履歴です。VPS移行後は閲覧・抽選の保存先として使用しません。
