# Y++ — Tools Portal

スマートフォン向けのY++ツール集約ホームページです。

## ページ構成

- 左上「Y++」、右上ハンバーガーメニュー
- 上部：3列×2行のツールカード（合計6件）。項目は site.config.json から読み込む
- 中部：Y-OBSをページ内表示。元リポジトリから閲覧用ファイルをコピー
- 下部：プロフィール。リンクと表示文言は site.config.json に配置
- 左上の「Y++」を6秒以内の間隔で10回タップすると設定ログイン画面を表示
- 設定画面：Y-OBSと同じVPS側APIによるPIN認証、認証済みの場合に現在の設定概要を表示
- メニューやプロフィールをブラウザ上で編集して保存する機能は未実装。将来、管理者専用APIで認証と編集データの永続化を実装予定

## セキュリティ

- 10回タップは設定画面への入口であり認証の代わりではありません。
- 管理用PINをサイトのソースコードやJSONに埋め込みません。
- HTTPSの POST /api/login と GET /api/admin/state の成功を確認して管理画面を開きます。
- 認証試行制限・アクセス禁止・トークン期限は既存のY-OBSサーバー側で処理します。3回失敗時の禁止を注意表示します。
- site.config.json は公開されます。秘密情報を絶対に記載しないでください。
- この設定画面のログインはGitHub書き込み権限を与えません。GitHubのアクセストークンをクライアント側に置きません。
- メニューリンクはHTTPSか内部アンカーのみ利用し、文字列をHTMLとして実行しません。

## ローカルプレビュー

このフォルダで python3 -m http.server 8080 を起動し、http://localhost:8080/ にアクセスしてください。

## Y-OBSの組み込み

閲覧用 y-obs/index.html, y-obs/config.js, y-obs/version.json は元のY-OBSからコピー。
VPSとOBS送信スクリプトの動作は変更しません。
iPhoneのPiPはSafari単独ページでの利用を推奨します。
