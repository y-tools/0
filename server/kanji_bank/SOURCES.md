# みんなで漢字 — 読み問題データ

5級・4級・3級・2級・準1級・1級、それぞれ2,000語、計12,000語。全体でも同じ表記の重複はありません。漢字2〜4字の語と、その語全体のひらがなの読みを収録しています。

これは**配当漢字の最上位級を目安に分類した独自の読み問題**です。漢検の公式過去問、公式問題集、公式の語彙難易度一覧ではありません。熟語の実際の難しさと漢字の配当級は必ずしも一致しません。

## 全件に適用した検証

1. JMdictの表記別の読み制限 `re_restr` を守り、仮名専用の読みを漢字に誤って割り当てない。
2. 同じ表記に対して辞書中の読みが一つだけである語を採用する。複数読みは不採用とする。
3. 非標準・稀用・旧用の表記や読み、古語・廃語・稀語・俗語・方言などの指定のある候補を除く。
4. 語全体の読みを、構成する各漢字の音訓に分解して再照合する。2〜5級では常用漢字表の読み、上位級の表外漢字ではKANJIDIC2の読みを用いる。連濁と促音化の候補は照合時に認めるが、読み自体は必ずJMdictに登録されたものをそのまま採用する。
5. 級は構成漢字中の最上位の配当級とし、配当外・分類不明・異体字のみの項目は採用しない。2〜4級の別転記との比較では「叱／𠮟」「頬／頰」「剥／剝」「填／塡」の字体差を常用漢字表の字体に揃えて確認する。
6. 辞書の優先表記と頻度指定を優先し、各級2,000語を選ぶ。全体の表記重複・級別件数・ひらがな・出典項目番号・各データファイルのSHA-256を確認する。

これは辞書照合と規則検証であり、12,000問すべてを人間の校閲者が校正したという意味ではありません。辞書の誤りや、文脈に依存する読みを完全に排除できる保証はありません。ゲームマスターは抽出画面で漢字と読みを確認してから追加できます。疑問のある問題は「この問題を除外」で以後の抽出から外せます。

## 保存と更新

`level-*.json` は `[漢字の語, ひらがなの読み, JMdict項目番号]` の配列です。`manifest.json` が級とファイルの対応・件数・整合性・版を管理します。サーバーの `import-bank` 操作が全ファイルを検証してからSQLiteへ一括保存します。不完全なデータは取り込みません。既存の手作り問題や参加者を変更しません。再取り込みしても除外と追加履歴を保持します。

辞書データは定期的に更新してください。`tools/` に再生成手順とコードを置いています。Webで公開する辞書派生データについては、EDRDGの更新条件に従い少なくとも月ごとに最新版の取得・差分確認・再検証・取り込みを行ってください。自動更新によって未確認の問題を勝手に出題する処理はありません。
